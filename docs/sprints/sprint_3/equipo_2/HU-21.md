## 1. Descripción de la Historia
**Como** estudiante o asesor de posgrado,  
**quiero** cargar archivos de evidencia (PDF, DOCX, ZIP, imágenes) vinculados a tutorías, acuerdos o avances de tesis,  
**para** respaldar documentalmente el trabajo académico realizado dentro de un límite seguro de 15MB por archivo.

---

## 2. Criterios de Aceptación y Validación (Gherkin)

### CA-21.1: Carga Exitosa de Archivo Local
```gherkin
Escenario: Carga de archivo PDF de evidencia académica
  Dado que un asesor o estudiante autenticado se encuentra en el repositorio de evidencias
  Cuando envía un formulario multipart a '/api/v2/evidence/' con archivo PDF menor a 15MB
  Entonces el sistema valida el tipo MIME y peso
  Y guarda el archivo en 'evidence/%Y/%m/'
  Y responde con HTTP 201 Created con "evidence_created_id", "mensaje": "Evidencia registrada correctamente".
```

### CA-21.2: Rechazo de Archivo Superior a 15MB
```gherkin
Escenario: Intento de carga de archivo superior a 15MB
  Dado que se adjunta un archivo con tamaño superior a 15 * 1024 * 1024 bytes
  Cuando se envía la solicitud
  Entonces el sistema responde con HTTP 400 Bad Request indicando que excede el límite de 15MB.
```

### CA-21.3: Rechazo de Formato No Permitido
```gherkin
Escenario: Intento de carga de archivo ejecutable o no admitido
  Dado que se adjunta un archivo .exe u otro no admitido
  Cuando se procesa la validación
  Entonces el backend responde con HTTP 400 Bad Request restringiendo el archivo a PDF, PNG, JPG, DOCX o ZIP.
```

## 3. Arquitectura e Implementación Técnica

### 3.1 Modelo de Datos (`backend/apps/evidence/models.py`)
- Modelo `Evidence`:
  - `student`: ForeignKey `Student`.
  - `semester`: ForeignKey `Semester` (opcional).
  - `tipo`: `ARCHIVO_LOCAL` o `ENLACE_DOI`.
  - `actividad_tipo`: `TUTORIA`, `ACUERDO`, `TESIS`, `OTRO`.
  - `actividad_id`: Identificador de entidad vinculada.
  - `titulo`, `descripcion`, `archivo_adjunto`, `enlace_url`.
  - `mime_type`, `file_size_bytes`, `fecha_carga`, `created_by`.

### 3.2 Endpoints y Filtros (`backend/apps/evidence/views.py`, `serializers.py`)
- `EvidenceViewSet` con soporte de `MultiPartParser`, `FormParser`, `JSONParser`.
- Filtros por `student`, `actividad_tipo`, `actividad_id`, `tipo`, `semester`.
- Permisos: `IsAssignedAdvisorOrStudent` con RBAC estricto.
