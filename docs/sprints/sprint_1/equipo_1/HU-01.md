## 2. Descripción de la Historia
**Como** usuario del sistema (Coordinador, Asesor o Estudiante),  
**quiero** iniciar sesión con mis credenciales institucionales (correo y contraseña),  
**para** acceder a las funcionalidades y datos protegidos correspondientes a mi rol.

---

## 3. Criterios de Aceptación (Gherkin)

### CA-01.1: Inicio de sesión exitoso con credenciales válidas
- **Dado** un usuario activo registrado en el sistema con correo y contraseña válidos,
- **Cuando** envía una solicitud `POST` a `/api/v2/auth/login/` con su payload de autenticación,
- **Entonces** el sistema responde con código HTTP `200 OK`,
- **Y** retorna un token JWT `access`, un token JWT `refresh` y el objeto de perfil `user` (`id`, `email`, `first_name`, `last_name`, `role`, `full_name`),
- **Y** el frontend almacena los tokens en almacenamiento seguro y actualiza el estado de autenticación (`AuthService.currentUser`, `AuthService.isAuthenticated`).

### CA-01.2: Rechazo ante credenciales incorrectas
- **Dado** un intento de inicio de sesión con correo inexistente o contraseña errónea,
- **Cuando** se envía la solicitud `POST` a `/api/v2/auth/login/`,
- **Entonces** el sistema responde con código HTTP `401 Unauthorized`,
- **Y** el mensaje de error no revela si el dato incorrecto fue el usuario o la contraseña para prevenir enumeración de usuarios.

### CA-01.3: Cierre de sesión seguro y revocación de acceso local
- **Dado** un usuario autenticado en la plataforma,
- **Cuando** ejecuta la acción de cerrar sesión (`logout`),
- **Entonces** el cliente limpia los tokens JWT y datos de sesión de `localStorage`,
- **Y** redirige inmediatamente a la vista de login (`/login`),
- **Y** cualquier intento posterior de consultar rutas protegidas (`/api/v2/auth/me/`, `/api/v2/students/`) es rechazado con `401 Unauthorized`.

## 4. Contrato de API REST v2.0

### Endpoint de Login
- **URL:** `/api/v2/auth/login/`
- **Método:** `POST`
- **Permisos:** `AllowAny`
- **Request Body:**
  ```json
  {
    "email": "asesor@nexus.edu.mx",
    "password": "Password123!"
  }
  ```
- **Response Exitosa (200 OK):**
  ```json
  {
    "access": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": 1,
      "email": "asesor@nexus.edu.mx",
      "first_name": "Carlos",
      "last_name": "Santana",
      "role": "ASESOR",
      "full_name": "Carlos Santana"
    }
  }
  ```

### Endpoint de Renovación de Token
- **URL:** `/api/v2/auth/refresh/` o `/api/v2/auth/token/refresh/`
- **Método:** `POST`
- **Request Body:**
  ```json
  {
    "refresh": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
  ```
- **Response Exitosa (200 OK):**
  ```json
  {
    "access": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
  ```

### Endpoint de Perfil de Usuario
- **URL:** `/api/v2/auth/me/`
- **Método:** `GET`
- **Cabeceras:** `Authorization: Bearer <access_token>`
- **Response Exitosa (200 OK):**
  ```json
  {
    "id": 1,
    "email": "asesor@nexus.edu.mx",
    "first_name": "Carlos",
    "last_name": "Santana",
    "full_name": "Carlos Santana",
    "role": "ASESOR",
    "is_active": true,
    "is_staff": false,
    "created_at": "2025-01-15T10:00:00Z",
    "updated_at": "2025-01-15T10:00:00Z"
  }
  ```
