## 2. Descripción de la Historia
**Como** Coordinador del Programa Doctoral,  
**quiero** registrar un nuevo estudiante en el sistema,  
**para** inicializar su expediente longitudinal de seguimiento académico.

---

## 3. Criterios de Aceptación (Gherkin)

### CA-03.1: Registro exitoso de estudiante
- **Dado** un usuario con rol de `COORDINADOR` autenticado,
- **Cuando** envía una solicitud `POST` a `/api/v2/students/` con los datos del estudiante (`matricula`, `nombre_completo`, `programa_doctoral`, `cohorte`),
- **Entonces** el sistema persiste la información en la base de datos,
- **Y** responde con código HTTP `201 Created` y payload estandarizado v2.0:
  `{ "student_created_id": <id>, "mensaje": "Estudiante registrado correctamente", "student": { ... } }`.

### CA-03.2: Prevención de matrículas duplicadas
- **Dado** un estudiante ya registrado con una matrícula específica (ej. `DOC-2024-001`),
- **Cuando** se intenta registrar otro estudiante con la misma matrícula (sin importar mayúsculas/minúsculas),
- **Entonces** el sistema rechaza la operación con código HTTP `400 Bad Request`,
- **Y** retorna un mensaje de validación detallado indicando que la matrícula ya existe.

### CA-03.3: Consulta y detalle del expediente
- **Dado** un estudiante registrado en la base de datos,
- **Cuando** se solicita `GET /api/v2/students/<id>/`,
- **Entonces** el sistema responde con HTTP `200 OK` retornando toda la información del estudiante, semestres asociados y metadatos de auditoría.

---

## 4. Contrato de API REST v2.0

### Endpoint: Registro de Estudiante
- **URL:** `/api/v2/students/`
- **Método:** `POST`
- **Cabeceras:** `Authorization: Bearer <access_token>`
- **Request Body:**
  ```json
  {
    "matricula": "DOC-2024-001",
    "nombre_completo": "Mariana Morales Ruiz",
    "programa_doctoral": "Doctorado en Ciencias Computacionales",
    "cohorte": "2024-A",
    "estatus_activo": true
  }
  ```
- **Response Exitosa (201 Created):**
  ```json
  {
    "student_created_id": 1,
    "mensaje": "Estudiante registrado correctamente",
    "student": {
      "id": 1,
      "user": null,
      "matricula": "DOC-2024-001",
      "nombre_completo": "Mariana Morales Ruiz",
      "programa_doctoral": "Doctorado en Ciencias Computacionales",
      "cohorte": "2024-A",
      "estatus_activo": true,
      "semesters": [],
      "total_semesters": 0,
      "created_at": "2025-01-15T10:00:00Z",
      "updated_at": "2025-01-15T10:00:00Z"
    }
  }
  ```

### Endpoint: Listado Paginado de Estudiantes
- **URL:** `/api/v2/students/?page=1`
- **Método:** `GET`
- **Response Exitosa (200 OK):**
  ```json
  {
    "count": 1,
    "next": null,
    "previous": null,
    "results": [
      {
        "id": 1,
        "matricula": "DOC-2024-001",
        "nombre_completo": "Mariana Morales Ruiz",
        "programa_doctoral": "Doctorado en Ciencias Computacionales",
        "cohorte": "2024-A",
        "estatus_activo": true,
        "total_semesters": 0
      }
    ]
  }
  ```

### Endpoint: Eliminación de Estudiante
- **URL:** `/api/v2/students/<id>/`
- **Método:** `DELETE`
- **Response Exitosa (200 OK):**
  ```json
  {
    "details": "Recurso eliminado correctamente",
    "success": true
  }
  ```
